## ⚡ Overview

Questo progetto è il mio biglietto da visita digitale. Non è solo una vetrina per i miei progetti, ma una dimostrazione pratica delle mie competenze nello sviluppo Frontend: **gestione del DOM, animazioni CSS avanzate, responsive design e accessibilità**.

Il design segue i principi del **Glassmorphism** e del minimalismo, con un'architettura del codice pulita e modulare, senza l'utilizzo di framework pesanti.

## ✨ Caratteristiche Principali

### 🎨 UI & Design System
- **Glassmorphism Theme:** Utilizzo avanzato di `backdrop-filter`, trasparenze e bordi sottili per creare profondità.
- **Tipografia:** Combinazione di *Space Grotesk* (Heading) e *Outfit* (Body) per un look tecnico ma leggibile.
- **Palette Colori:** Tema Dark Mode nativo con accenti variabili (`--accent`, `--dieti`, `--dev`) gestiti tramite **CSS Variables**.

### 🛠️ Ingegnerizzazione
- **Zero Frameworks:** Costruito in **Vanilla JS, HTML5 e CSS3** per massimizzare le performance e il controllo.
- **Pixel Perfection:** Gestione avanzata del rendering (anti-aliasing, pixel snapping fix) per icone e bordi sempre nitidi.

### 🚀 SEO & Performance
- **JSON-LD Structured Data:** Schema.org integrato per *Person* e *Projects*.
- **Ottimizzazione Assets:** Formati WebP, preloading dei font e gestione asincrona delle immagini.
- **Responsive:** Layout fluido che si adatta da schermi 4K fino a dispositivi mobili (320px) utilizzando CSS Grid e Flexbox.
